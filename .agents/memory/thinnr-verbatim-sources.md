Rule: Patient-facing THINNR program wording (phases, foods lists, instructions, knowledge-base Q&A) must be quoted exactly from the verbatim archive under docs/thinnr-program/ — never paraphrased, summarized, spell-"fixed", or reordered. Apparent typos are intentional-to-preserve. The source PDF/paste beats any transcription if they disagree.

**Why:** The program is an official medical protocol and the owner required exact official wording for all downstream use (features, guidance, seeding). The originals contain oddities (stray parens, spacing like "6- 24 hours") that must survive copying; silent "corrections" are the failure mode.

**How to apply:** When a feature or seed needs program text, read the archive files instead of writing from memory. Mind the page-numbering offset (printed footer = PDF page + 1). If a page's text seems missing from the transcription, check a render of the PDF page — one page's food tables exist only as graphics and live in a bracketed appendix of that page block. When transcribing from renders, confirm small glyphs (e.g. ½ vs ⅓ fractions) from 600-dpi crops — a 200-dpi read once got a food amount wrong.
