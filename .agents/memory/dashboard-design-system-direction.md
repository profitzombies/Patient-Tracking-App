---
name: Dashboard design-system direction
description: The approved conceptual blend to preserve when formalizing the dashboard design system.
---

Use a guided-operations hybrid: systematic modular foundations, an editorial reading hierarchy, and a contained action layer.

**Why:** The user chose a hybrid after comparing system-oriented, narrative, and command-oriented dashboard concepts. The blend should avoid both generic widget repetition and an alarm-heavy control center.

**How to apply:** Lead with a clear interpretation of business health, organize supporting evidence through reusable primitives, and keep priority actions visible but spatially contained. Preserve this hierarchy when extracting tokens, components, and usage guidance.
