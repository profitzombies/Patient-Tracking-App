description: Basic entitlement and licensing pitfalls when evaluating FatSecret alongside THINNR food sources

Do not treat a FatSecret key, an edition's marketing table, or the public
24-hour content-removal rule as permission to persist nutrition or use it for
THINNR advice. The Basic editions table excludes caching; the standard search
documentation has a `premier` scope label despite advertised Basic search.
Resolve access from the actual grant and bounded standard-method probes, not
by requesting extra scopes.

**Why:** The public documentation checked on 2026-09-10 is inconsistent on
standard search entitlement, while public terms restrict advice and durable
content storage. THINNR's immutable patient history cannot be retroactively
refreshed or deleted to fit a provider retention rule.

**How to apply:** Re-check current official terms and any actual agreement.
Evaluate transiently with public/synthetic queries and derived metrics only;
keep patient histories and AI Coach outside the evaluation. Require explicit
permission for every intended storage/display/advice use before activation.
