What are the possible values of OrderStatus, and which one means the order has shipped? Do you ever report "delivered", or does the status stop at shipped with a tracking number? See table below for order statuses. Shipped and Closed status both indicate an order has been shipped. We do not report delivered in this API (but there is a separate optional shipping API which does)
 
Order Status
Description
Imported
An order that has been imported.
Created
A manually created order.
On Hold
The order has been set aside and is not currently being fulfilled. The items are also not included in the reserved inventory amount.
Editing
A newly created or cloned order that has not yet been released for fulfillment.
Modified
An imported order that has been manually modified.
Reset
An order which has been reset back to a pre-printed status.
Back Order
Orders calling for an item quantity that would put the reserved inventory amount below zero.
Released Back Order
An order on back order that has been released so it can be committed.
Committed
An order which has inventory committed to it and is ready to be fulfilled.
Being Fulfilled
Packing slip has been printed and the order has been sent to the warehouse floor.
Fulfilled
Order has been picked and the inventory has been deducted.
Shipped
The tracking number has been uploaded to the order.
Closed
The tracking information for the order has been exported and sent to the client.
Cancelled
The order is no longer being fulfilled and the items have been returned to inventory.
